# BloomNexus

Manages user authentication and authorization for distributed applications using a simple and secure centralized identity management system.

BloomNexus is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Manages user authentication and authorization
- for distributed applications using a
- simple and secure centralized identity

## Key Features

- Manages user authentication and authorization
- for distributed applications using a
- simple and secure centralized identity

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/BloomNexus.git`
2. `cd BloomNexus`
3. Install in editable mode: `pip install -e .`

## Configuration

BloomNexus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
